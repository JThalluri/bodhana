# Word Practice and Statement paper

Implemented 2026-10-26 as phase 1, under Writing Worksheets > Handwriting Lines > Format > Word Practice. The supplied word_practice_prototype.html is reference material only, retained untouched. No prototype code, CDN or dependency was imported.

Three columns read left to right. Content accepts whitespace/comma/semicolon/pipe-separated words and reuses the existing local dictionary picker. Choose Words only (one underline per word row), Practice lines (1-5 rows beneath each word row), or Full page (blank ruling, retaining the word list). Primary head/mid/base and single ruling reuse Lines controls, spacing and colors. Full-page ruling is emitted once per row, not per cell. Long words wrap by measured characters. Rows paginate explicitly, capped at the existing 20 pages with a visible warning if exceeded. Fonts, letter spacing, typography, margins, themes, fitting, storage, Print and Export use existing Bodhana paths. Word Practice uses 8-44 px text; entering from automatic sizing starts at 20 px. Existing page margins are retained; 0.25 in is a useful choice for three columns. Picture/reference boxes, baseline shift and the separate margin line do not apply to this format and their controls are unavailable. Seyes-style ruling remains available in the other handwriting formats, not Word Practice.

Paper stock is a shared component: src/shared/paper-size.js defines Letter and Statement, printable pages declare data-paper-size, and shared print/export derives physical dimensions from it. Statement is 528 x 816 CSS pixels and 396 x 612 PDF points. All Handwriting Lines formats support both stocks and regenerate at the real page width/height. Letter remains the default and old saved workspaces gain defaults without resetting existing settings or dictionary selection. Preview fitting uses actual page dimensions; it never changes physical output. One print job supports one paper stock; accidental mixed stocks are rejected. Certificates retain their existing Letter landscape adapter.

Phase 2: extend every remaining printable worksheet family through generator-specific reflow, pagination and controls. See docs/BACKLOG.md. This phase is explicitly separate from introducing Word Practice; the current change does not advertise Statement in unconverted families or shrink Letter content. Dedicated Seyes geometry and its print path remain unchanged. Dictionary Builder is a results view.

Validation commands: npm test; npm run build; npm run build:hosted; npm run audit:build; npm run test:portal. Focused production checks: npm run test:portal -- --grep "Word Practice|Handwriting Statement". Production artifacts are dist/index.html (portable file) and dist-hosted/ (hosted /gurukool/). Screenshots, generated print PDFs and actual downloaded export PDFs are under artifacts/*word-practice*. Physical printer calibration and Android installed-mode testing require real devices. No deployment is claimed by local validation.

Artifact review also found and corrected a pre-existing export font fallback. SVG foreignObject rendering now embeds the matching bundled font-face declarations rather than relying on family names alone. Inspected the JPEG extracted from the actual downloaded PDF: Andika text now matches the worksheet/print appearance. Narrow-column single-character overflow is reported as a visible warning rather than hidden.
